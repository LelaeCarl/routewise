How per-leg costs are derived during routing.

← Dashboard

Current model

Per-leg shipment cost uses a weight-based model in the routing engine: air: cost = max(chargeable_weight_kg × cost_per_kg, minimum_charge); other modes: cost = max(base_cost + weight_kg × cost_per_kg, minimum_charge).

If dimensions are provided (cm), air uses volumetric weight: volumetric = (L×W×H)/6000, chargeable = max(actual, volumetric).

Edge attributes (base cost, per-kg rate, minimum charge) drive computation. Editing is disabled in this phase for stability.
